# Search Decode

Simple extension that instantly decodes Base64 searches. This build is intended for chromium based browsers.


## Modes

### URL ONLY
Only decodes when the output looks like a valid link

### URL + TEXT
Decodes links and normal text.

## Example



**Input:**

```aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8=```



**Output:**

```https://www.google.com/```
